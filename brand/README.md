# Yeknom Logo

The mark turns the letter **Y** into three component paths meeting at one
signal node. Its shorter amber branch and longer rising blue-green branch give
the mark a forward direction without losing the original workbench structure:

- amber is the default `signal` color;
- blue-green is the default `active` color;
- the pale stem is `trace`;
- the dark rounded tile represents the `workbench` and its modules.

## Files

- `yeknom-logo-mark.svg` — primary standalone mark.
- `yeknom-logo-lockup.svg` — horizontal product name lockup.
- `yeknom-logo-monochrome.svg` — one-color print and engraving source.
- `yeknom-app-icon.svg` — 1024 × 1024 application icon source.
- `yeknom-maskable-icon.svg` — crop-safe PWA icon source.

The desktop icon uses an 832 × 832 outer tile on the 1024 × 1024 canvas. This
roughly 81% occupancy keeps its apparent size aligned with common macOS Dock
icons; do not scale the tile to the canvas edges.

Keep clear space around the mark equal to the center signal dot's diameter.
Do not recolor individual paths arbitrarily, add effects, or place the primary
mark directly on a similarly dark background.

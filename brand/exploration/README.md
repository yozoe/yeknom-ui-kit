# V2 exploration — Signal Forge

This direction deliberately exaggerates the original three-path idea:

- broad, pointed arms make the **Y** more theatrical;
- layered highlights turn the paths into forged signal ribbons;
- a hexagonal housing and diamond core emphasize the convergence point;
- the tapered stem reads as both a trace and a downward energy blade;
- subtle frame rails keep the mark connected to the workbench UI language.

The original logo and all currently integrated application icons remain
unchanged. These files are exploration assets only.

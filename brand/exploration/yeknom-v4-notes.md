# V4 exploration — Forward Flow

V4 keeps the V3 curve language but changes the branch lengths:

- the amber `signal` branch is shorter and sits slightly lower;
- the blue-green `active` branch is longer and rises further;
- the stable center node and trace stem keep the asymmetric mark balanced;
- color, stroke weight, highlights, and workbench tile remain unchanged.

The previous logo variants and integrated application icons remain unchanged.

# V3 exploration — Soft Flow

V3 returns to the original logo rather than extending the angular V2:

- the tile, palette, stroke weight, and signal node remain familiar;
- both upper arms use restrained S-curves instead of straight diagonals;
- the trace stem has a subtle counter-curve to avoid looking mechanical;
- narrow highlights add depth without turning the mark into an illustration.

The original logo and integrated application icons remain unchanged.
